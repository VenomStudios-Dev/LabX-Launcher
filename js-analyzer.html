What the analyzer checks

The analyzer combines the browser's JavaScript parser with targeted source-level rules.

Syntax validationChecks whether the source can be parsed by the browser's JavaScript engine. The source is compiled for validation but never executed.
Correctness and maintainabilityFlags loose equality, legacy var declarations, debugger statements, and empty catch blocks.
Security-sensitive patternsHighlights eval, dynamic Function construction, document.write, string-based timers, and assignments to innerHTML.
Developer remindersFinds TODO/FIXME comments and common console logging that may need attention before release.
This is a static, rule-based analyzer—not an AI system and not a complete substitute for ESLint, TypeScript, tests, or a security review. Some findings require human judgment. It does not execute your source code.
